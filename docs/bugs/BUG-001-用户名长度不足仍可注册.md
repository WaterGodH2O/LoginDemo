# BUG-001 不足 6 位的用户名可以注册成功

| 项 | 内容 |
| --- | --- |
| 编号 | BUG-001 |
| 标题 | 不足 6 位的用户名可以注册成功 |
| 严重程度 | 高 |
| 状态 | 新建 |
| 所属需求 | REQ-REG-002 |
| 关联用例 | TC-UI-REG-002、TC-API-REG-003 |
| 发现日期 | 2026-10-07 |
| 环境 | 前端地址 `/`；账号服务 `http://localhost:5000` |
| 来源 | 测试报告 v1.0、测试执行记录 |

## 复现步骤

页面：

1. 打开注册页。
2. 用户名填写 `abcde`，密码和确认密码都填写 `Pass1234`。
3. 点击注册。

接口：

1. `POST http://localhost:5000/api/register`，请求体 `{"username":"abcde","password":"Pass1234"}`。
2. `POST http://localhost:5000/api/login`，请求体 `{"username":"abcde","password":"Pass1234"}`。

## 预期结果

用户名去掉首尾空格后少于 6 位时，注册失败，不创建账号，并提示用户名长度不足。该用户名不能作为已注册账号登录。

## 实际结果

页面上，不合法用户名可以注册成功。

接口上，注册返回 HTTP 201，提示「注册成功」。随后登录返回 HTTP 200，响应中的用户名为 `abcde`。

页面和接口都没有拦住不足 6 位的用户名。
