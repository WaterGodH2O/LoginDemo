# 需求规格说明书：登录注册 Demo

## 1. 总体描述

系统提供注册、登录和登录状态查看。页面与账号服务分开运行。账号保存后，服务重启仍然保留。登录状态只存在于当前浏览器会话中。

优先级约定：

- 高：不满足则注册、登录或退出的主流程不能按 PRD 验收。
- 中：页面之间的入口。缺少时主流程仍可用其他方式到达。

## 2. 功能需求

### 2.1 注册

#### REQ-REG-001 用户名必填

| 项      | 内容                            |
| ------ | ----------------------------- |
| 需求描述   | 注册时用户名必填。提交前去掉首尾空格，去掉后为空则拒绝注册 |
| 前置条件   | 打开注册页                         |
| 输入     | 用户名为空，或只含空格                   |
| 预期结果   | 不创建账号，并提示需要输入用户名              |
| 优先级    | 高                             |
| PRD 来源 | 5.1                           |

#### REQ-REG-002 用户名长度不足

| 项      | 内容                              |
| ------ | ------------------------------- |
| 需求描述   | 用户名长度按去掉首尾空格后的字符数计算，少于 6 位则拒绝注册 |
| 前置条件   | 打开注册页                           |
| 输入     | 去掉首尾空格后长度为 1 至 5 的用户名，密码非空且两次一致 |
| 预期结果   | 不创建账号，并提示用户名长度不足                |
| 优先级    | 高                               |
| PRD 来源 | 5.1                             |

#### REQ-REG-003 用户名长度达到 6 位

| 项      | 内容                              |
| ------ | ------------------------------- |
| 需求描述   | 去掉首尾空格后长度不少于 6 位的新用户名，不因长度规则被拒绝 |
| 前置条件   | 该用户名尚未注册                        |
| 输入     | 去掉首尾空格后长度等于 6 的用户名，密码非空且两次一致    |
| 预期结果   | 长度规则不导致失败，注册可以继续并成功             |
| 优先级    | 高                               |
| PRD 来源 | 5.1、验收标准                        |

#### REQ-REG-004 用户名不可重复

| 项      | 内容                               |
| ------ | -------------------------------- |
| 需求描述   | 用户名不能与已有账号重复。比较的是去掉首尾空格后的用户名     |
| 前置条件   | 已存在用户名 `user01`                  |
| 输入     | 再次注册 `user01`，或首尾带空格的 ` user01 ` |
| 预期结果   | 不创建新账号，并提示「用户名已存在」               |
| 优先级    | 高                                |
| PRD 来源 | 5.1、7                            |

#### REQ-REG-005 密码必填

| 项      | 内容                  |
| ------ | ------------------- |
| 需求描述   | 密码必填，不能为空。密码不去掉首尾空格 |
| 前置条件   | 打开注册页；用户名为有效用户名     |
| 输入     | 密码为空                |
| 预期结果   | 不创建账号，并提示需要输入密码     |
| 优先级    | 高                   |
| PRD 来源 | 5.1                 |

#### REQ-REG-006 确认密码一致

| 项      | 内容                              |
| ------ | ------------------------------- |
| 需求描述   | 确认密码必填，且必须与密码一致。不一致时不允许提交注册     |
| 前置条件   | 打开注册页；用户名为有效用户名                 |
| 输入     | 密码与确认密码不同；或确认密码为空               |
| 预期结果   | 不提交注册，不创建账号，并提示两次密码不一致或需要再次输入密码 |
| 优先级    | 高                               |
| PRD 来源 | 5.1                             |

#### REQ-REG-007 注册成功

| 项      | 内容                            |
| ------ | ----------------------------- |
| 需求描述   | 注册成功后提示成功，进入登录页，已填写的密码不在页面上保留 |
| 前置条件   | 使用尚未占用的有效用户名                  |
| 输入     | 用户名、密码、确认密码均合法                |
| 预期结果   | 提示注册成功，进入登录页；登录页不带出刚才的密码      |
| 优先级    | 高                             |
| PRD 来源 | 5.1                           |

#### REQ-REG-008 注册页进入登录页

| 项      | 内容         |
| ------ | ---------- |
| 需求描述   | 注册页可以进入登录页 |
| 前置条件   | 打开注册页      |
| 输入     | 选择前往登录     |
| 预期结果   | 进入登录页      |
| 优先级    | 中          |
| PRD 来源 | 4          |

### 2.2 登录

#### REQ-LOGIN-001 登录信息必填

| 项      | 内容                             |
| ------ | ------------------------------ |
| 需求描述   | 登录时用户名和密码均必填。用户名去掉首尾空格后为空则拒绝登录 |
| 前置条件   | 打开登录页                          |
| 输入     | 用户名为空或只含空格；或密码为空               |
| 预期结果   | 登录失败，不进入首页，并提示所缺字段             |
| 优先级    | 高                              |
| PRD 来源 | 5.2                            |

#### REQ-LOGIN-002 凭证正确

| 项      | 内容                                                |
| ------ | ------------------------------------------------- |
| 需求描述   | 用户名和密码与已注册账号一致时登录成功。用户名先去掉首尾空格，再与已保存用户名比较；密码按原样比较 |
| 前置条件   | 已注册 `user01` 及对应密码                                |
| 输入     | 用户名 `user01` 或首尾带空格的同一用户名，密码正确                    |
| 预期结果   | 登录成功，进入首页，首页显示该用户名                                |
| 优先级    | 高                                                 |
| PRD 来源 | 5.2、验收标准                                          |

#### REQ-LOGIN-003 凭证错误

| 项      | 内容                                     |
| ------ | -------------------------------------- |
| 需求描述   | 用户名不存在或密码不正确时登录失败。两种情况使用同一提示，不说明是哪一项错误 |
| 前置条件   | 已注册 `user01`                           |
| 输入     | 不存在的用户名，或 `user01` 配错误密码               |
| 预期结果   | 登录失败，停留在登录流程，提示「用户名或密码错误」              |
| 优先级    | 高                                      |
| PRD 来源 | 5.2                                    |

#### REQ-LOGIN-004 登录页进入注册页

| 项      | 内容         |
| ------ | ---------- |
| 需求描述   | 登录页可以进入注册页 |
| 前置条件   | 打开登录页      |
| 输入     | 选择前往注册     |
| 预期结果   | 进入注册页      |
| 优先级    | 中          |
| PRD 来源 | 5.2        |

### 2.3 首页与退出

#### REQ-HOME-001 已登录展示

| 项      | 内容                                |
| ------ | --------------------------------- |
| 需求描述   | 已登录时，首页显示「已登录」、当前用户名和本次登录时间，并提供退出 |
| 前置条件   | 刚刚登录成功                            |
| 输入     | 打开首页                              |
| 预期结果   | 状态为「已登录」；用户名与登录账号一致；登录时间有值；可以看到退出 |
| 优先级    | 高                                 |
| PRD 来源 | 5.3                               |

#### REQ-HOME-002 未登录展示

| 项      | 内容                                 |
| ------ | ---------------------------------- |
| 需求描述   | 未登录时，首页显示「未登录」，用户名和登录时间为空，并可以前往登录页 |
| 前置条件   | 当前浏览器没有有效登录状态                      |
| 输入     | 打开首页                               |
| 预期结果   | 状态为「未登录」；用户名和登录时间为空；可以进入登录页        |
| 优先级    | 高                                  |
| PRD 来源 | 5.3                                |

#### REQ-HOME-003 退出后保持未登录

| 项      | 内容                               |
| ------ | -------------------------------- |
| 需求描述   | 退出成功后，首页恢复为未登录。同一浏览器再次打开首页，仍为未登录 |
| 前置条件   | 当前已登录                            |
| 输入     | 退出，然后再次打开首页                      |
| 预期结果   | 退出后立即显示「未登录」且不再显示该用户名；再次打开首页结果相同 |
| 优先级    | 高                                |
| PRD 来源 | 5.3、验收标准                         |

## 3. 非功能需求

#### REQ-NF-001 前后端分离

| 项      | 内容                                 |
| ------ | ---------------------------------- |
| 需求描述   | 页面与账号服务分开运行。注册、登录、查询登录状态和退出都通过接口完成 |
| 预期结果   | 页面不直接读写账号存储；上述四项操作均能经接口完成          |
| 优先级    | 高                                  |
| PRD 来源 | 7                                  |

#### REQ-NF-002 账号持久保存

| 项      | 内容                  |
| ------ | ------------------- |
| 需求描述   | 注册成功的账号在账号服务重启后仍然保留 |
| 预期结果   | 重启后仍可用原用户名和密码登录     |
| 优先级    | 高                   |
| PRD 来源 | 7                   |

#### REQ-NF-003 登录状态限于当前会话

| 项      | 内容                               |
| ------ | -------------------------------- |
| 需求描述   | 登录状态保持在当前浏览器会话中。退出或会话结束后不再视为已登录  |
| 预期结果   | 未退出时，同一浏览器刷新首页仍为已登录；退出或会话失效后为未登录 |
| 优先级    | 高                                |
| PRD 来源 | 7                                |
