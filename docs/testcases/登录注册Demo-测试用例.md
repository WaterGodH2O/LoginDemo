# 测试用例V1.0：登录注册 Demo

## 1. 手工用例

### 1.1 注册

#### TC-UI-REG-001 用户名为空或只有空格

| 项    | 内容                                                           |
| ---- | ------------------------------------------------------------ |
| 对应需求 | REQ-REG-001                                                  |
| 测试方式 | 手工                                                           |
| 优先级  | 高                                                            |
| 前置条件 | 打开注册页                                                        |
| 步骤   | 1. 用户名留空，密码和确认密码都填写 `Pass1234`，点击注册。2. 用户名改为三个空格，密码不变，再次点击注册 |
| 预期结果 | 两次都不提交注册，不创建账号，都提示「请输入用户名」                                   |

#### TC-UI-REG-002 用户名长度不足

| 项    | 内容                                                                                 |
| ---- | ---------------------------------------------------------------------------------- |
| 对应需求 | REQ-REG-002                                                                        |
| 测试方式 | 手工                                                                                 |
| 优先级  | 高                                                                                  |
| 前置条件 | 打开注册页；`abcde` 尚未注册                                                                 |
| 步骤   | 1. 用户名填写 `abcde`，密码和确认密码都填写 `Pass1234`，点击注册。2. 用户名改为 `  abcde`（前面两个空格），密码不变，再次点击注册 |
| 预期结果 | 两次都不创建账号，并提示用户名长度不足。第 2 次按去掉首尾空格后的 5 位计算                                           |

#### TC-UI-REG-003 注册成功

| 项    | 内容                                                                       |
| ---- | ------------------------------------------------------------------------ |
| 对应需求 | REQ-REG-003、REQ-REG-007                                                  |
| 测试方式 | 手工                                                                       |
| 优先级  | 高                                                                        |
| 前置条件 | `user01` 尚未注册                                                            |
| 步骤   | 1. 用户名填写 ` user01 `（首尾各一个空格）。2. 密码和确认密码都填写 `Pass1234`。3. 点击注册，并查看跳转后的登录页 |
| 预期结果 | 去掉空格后为 6 位，不因长度被拒绝。提示「注册成功，请登录」，进入登录页。                                   |

#### TC-UI-REG-004 用户名重复

| 项    | 内容                                                                           |
| ---- | ---------------------------------------------------------------------------- |
| 对应需求 | REQ-REG-004                                                                  |
| 测试方式 | 手工                                                                           |
| 优先级  | 高                                                                            |
| 前置条件 | 已存在 `user01`                                                                 |
| 步骤   | 1. 用户名填写 `user01`，密码和确认密码都填写 `Pass1234`，点击注册。2. 用户名改为 ` user01 `，密码不变，再次点击注册 |
| 预期结果 | 两次都不创建新账号，都提示「用户名已存在」                                                        |

#### TC-UI-REG-005 密码与确认密码

| 项    | 内容                                                                                                                          |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| 对应需求 | REQ-REG-005、REQ-REG-006                                                                                                     |
| 测试方式 | 手工                                                                                                                          |
| 优先级  | 高                                                                                                                           |
| 前置条件 | 每次从空白注册页开始                                                                                                                  |
| 步骤   | 1. 用户名填写 `newuser`，密码和确认密码都留空，点击注册。2. 用户名仍为 `newuser`，密码填写 `Pass1234`，确认密码留空，点击注册。3. 密码填写 `Pass1234`，确认密码填写 `Pass5678`，点击注册 |
| 预期结果 | 三次都不提交注册，不创建账号。第 1 次提示「请输入密码」；第 2 次提示「请再次输入密码」；第 3 次提示「两次输入的密码不一致」                                                          |

#### TC-UI-NF-001 页面通过接口完成账号操作

| 项    | 内容                                                                                           |
| ---- | -------------------------------------------------------------------------------------------- |
| 对应需求 | REQ-NF-001                                                                                   |
| 测试方式 | 手工                                                                                           |
| 优先级  | 高                                                                                            |
| 前置条件 | 打开浏览器的网络记录；账号服务已启动                                                                           |

## 2. 接口用例

请求发往 `http://localhost:5000`。需要登录状态的用例，使用同一会话连续请求。
