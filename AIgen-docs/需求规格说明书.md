# 需求规格说明书

## 1. 总体描述
本系统为一个简易 Web 注册与登录系统，允许用户进行账号注册、登陆和查看状态。系统通过接口与服务进行交互，专注于账号的创建和管理。

## 2. 功能需求

#### REQ-REG-001 用户注册

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户可以在注册页填写用户名和密码，创建新账号 |
| 前置条件 | 打开注册页 |
| 输入 | 用户名（去掉首尾空格后最少 6 位）、密码、确认密码 |
| 预期结果 | 账号保存成功，用户前往登录 |
| 优先级 | 高 |
| PRD 来源 | 5.1 |

#### REQ-REG-002 用户名长度不足

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户名长度按去掉首尾空格后的字符数计算，少于 6 位则拒绝注册 |
| 前置条件 | 打开注册页 |
| 输入 | 去掉首尾空格后长度为 1 至 5 的用户名，密码非空且两次一致 |
| 预期结果 | 不创建账号，并提示用户名长度不足 |
| 优先级 | 高 |
| PRD 来源 | 5.1 |

#### REQ-REG-003 用户名重复

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户名不能与已有账号重复，重复时注册失败 |
| 前置条件 | 打开注册页 |
| 输入 | 已存在的用户名，密码及确认密码 |
| 预期结果 | 不创建账号，并提示用户名已存在 |
| 优先级 | 高 |
| PRD 来源 | 5.1 |

#### REQ-REG-004 密码不能为空

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户在注册时必须提供密码，不能为空 |
| 前置条件 | 打开注册页 |
| 输入 | 用户名有效，密码为空或未填写 |
| 预期结果 | 不创建账号，并提示请输入密码 |
| 优先级 | 高 |
| PRD 来源 | 5.1 |

#### REQ-REG-005 确认密码一致性

| 项 | 内容 |
| --- | --- |
| 需求描述 | 确认密码必填，且必须与密码一致 |
| 前置条件 | 打开注册页 |
| 输入 | 用户名有效，密码与确认密码不一致 |
| 预期结果 | 不创建账号，并提示两次输入的密码不一致 |
| 优先级 | 高 |
| PRD 来源 | 5.1 |

#### REQ-LOGIN-001 用户登录

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户可以在登录页输入已注册的用户名和密码，登录系统 |
| 前置条件 | 打开登录页 |
| 输入 | 用户名、密码 |
| 预期结果 | 登录成功，进入首页并显示当前用户 |
| 优先级 | 高 |
| PRD 来源 | 5.2 |

#### REQ-LOGIN-002 用户名或密码错误

| 项 | 内容 |
| --- | --- |
| 需求描述 | 当用户名或密码错误时，登录失败 |
| 前置条件 | 打开登录页 |
| 输入 | 不存在的用户名或错误的密码 |
| 预期结果 | 登录失败，并提示用户名或密码错误 |
| 优先级 | 高 |
| PRD 来源 | 5.2 |

#### REQ-HOME-001 查看登录状态

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户在首页可以查看当前的登录状态 |
| 前置条件 | 用户已成功登录 |
| 输入 | 无 |
| 预期结果 | 显示登录状态、用户名和登录时间 |
| 优先级 | 高 |
| PRD 来源 | 5.3 |

#### REQ-HOME-002 退出登录

| 项 | 内容 |
| --- | --- |
| 需求描述 | 用户可以退出登录，恢复为未登录状态 |
| 前置条件 | 用户已成功登录 |
| 输入 | 无 |
| 预期结果 | 退出成功，首页恢复为未登录状态 |
| 优先级 | 高 |
| PRD 来源 | 5.3 |

## 3. 非功能需求

| 需求描述 | 页面与账号服务分开运行，通过接口完成注册、登录、查询和退出操作 |

| 输入 | 无 |
| 预期结果 | 页面与服务灵活分开 |
| 优先级 | 中 |
| PRD 来源 | 7.1 |
