## 自动化测试全流程插件原型 + React+Flask 登录注册Demo系统开发

#### 项目背景

为落地AI驱动的一站式自动化测试插件（覆盖PRD分析→需求拆解→测试用例设计→用例执行→测试报告生成→自动提Bug全链路），因无公司内部系统权限，先落地最小可验证Demo：基于React+Flask开发简易登录注册Web系统，人工预埋功能性Bug，配套输出PRD、需求分析、测试用例、测试报告、Bug单，验证AI自动化测试全流程可行性，为后续开发正式插件做原型沉淀。

### 核心职责

1. 设计并开发前端React + 后端Flask 简易登录注册Demo系统，实现账号注册、登录基础功能；

2. 刻意预埋业务规则类Bug：需求要求用户名长度≥6位，代码未做长度限制校验；

3. 输出完整PRD文档、需求分析、测试用例设计、手工/自动化用例执行记录、测试报告；

4. 基于发现的预埋Bug，标准化提交Bug单，模拟插件自动提Bug流程；

5. 梳理插件整体架构方案：PRD文本解析→需求结构化→用例生成→接口/页面自动化执行→报告生成→Bug推送，完成最小原型闭环。

### 技术栈

• 前端：React、Axios、React Router、Ant Design

• 后端：Flask、Python、SQLite（极简数据存储）

• 测试：手工测试、接口测试、Bug管理规范、测试报告结构化输出

• 插件方向：大模型PRD解析、Prompt工程、用例自动生成逻辑设计

### 项目产出

1. 可运行的前后端分离登录注册Demo（含预埋Bug）；

2. 完整配套文档：PRD、需求规格说明书、测试用例、测试报告、Bug单；

3. AI自动化测试插件最小原型设计方案（任务拆解+执行链路）；

4. 简历可复用：完整全流程交付物、开发+测试+AI插件设计的复合能力体现。
