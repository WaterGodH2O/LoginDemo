本地示例 · HTML + CSS + JavaScript

网页显示过程里发生了什么

浏览器先把 HTML 变成一棵可修改的 DOM 树，再用 CSS 决定外观，最后画到屏幕上。 JavaScript 不直接画像素，它读写 DOM、监听事件，屏幕跟着变。

建议同时打开开发者工具（F12）→ Elements，对照右侧实验区。
