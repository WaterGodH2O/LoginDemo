液态变形 · border-radius 关键帧

CSS 没有「流体」指令，但可以让圆角四个值各自呼吸，再叠一层 hue-rotate。

太阳系 · 嵌套旋转

父元素转轨道，子元素再转月球。全是 transform: rotate()。

透视悬停

rotateX / rotateY / translateZ。卡片不是 3D 模型，只是一个矩形在假装有厚度。

玻璃拟态

半透明底 + backdrop-filter: blur。背后极光被磨砂，这是滤镜，不是新图层类型。

扫光按钮

伪元素上的斜向渐变周期性横穿。下面这颗「按钮」也不是组件，是 span。

PREDEFINED

翻转卡 · checkbox 黑客

点卡片翻转。状态存在 :checked 里，不是变量、不是脚本。

背景那团会转的光，靠 @property --spin 让角度能被动画驱动，再喂给 conic-gradient(from var(--spin))。 普通自定义属性不能直接插值角度，这个注册语法是现代 CSS 才有的「预定义能力升级」。
选项卡本身也是 CSS：隐藏的 radio + :has(#tab-2:checked) 决定显示哪一块。 HTML 仍然只提供结构（三个面板都在），CSS 负责显隐，没有 display 之外的逻辑。
做不到的：发请求、记住用户、随机数、物理引擎、逐像素画画。 再花哨也是在浏览器已经实现的绘制指令里组合。这就是上一问的结论的现场版。
