# 测试流水线使用说明

在仓库根目录运行。程序读取前后端源码和 PRD，调用大模型生成测试用例和页面脚本，再启动本机的登录注册 Demo 并执行。通过与否由脚本比较，不由模型直接判定。

产品代码不会被修改，用户名长度校验也不会被补上。

## 准备

1. 使用仓库里的 Python。后端依赖：

```powershell
pip install -r backend/requirements.txt
```

需要能导入 `flask` 和 `flask-cors`。缺了的话，流水线在启动服务前退出。

2. 安装 Node.js，并确认 `node`、`npm` 在 PATH 中。本机两者位于 `B:\NodeJs\`。

3. 设置模型密钥。密钥只从环境变量读取，不要写进命令行或文件。

```powershell
$env:LLM_API_KEY = "你的密钥"
```

默认请求 `https://api.openai.com/v1/chat/completions`，模型名 `gpt-4o-mini`。DeepSeek、通义兼容模式、Kimi 等使用同一套 `messages` 格式时，用 `--llm-base-url` 和 `--llm-model` 换成对应地址和模型名。

4. 页面用例会在需要时安装 Playwright 和 Chromium。也可以事先安装：

```powershell
pip install playwright
python -m playwright install chromium
```

## 运行

在 `B:\cs\Internship` 执行：

```powershell
python pipeline/run.py
```

不传参数时使用这些默认值：

| 参数 | 默认 |
| --- | --- |
| `--source` | `frontend`、`backend` |
| `--prd` | `docs/prd/登录注册Demo-PRD.md` |
| `--web-base` | `http://localhost:5173` |
| `--api-base` | `http://localhost:5000` |
| `--channel` | `all` |
| `--llm-base-url` | `https://api.openai.com/v1` |
| `--llm-model` | `gpt-4o-mini` |
| `--codegen-retries` | `3` |
| `--locate-rounds` | `2` |
| `--timeout` | `30` |
| `--work-dir` | `pipeline/work` |

`--source` 必须同时包含前端目录和后端目录。目录不存在，或 PRD 文件不存在，或未设置 `LLM_API_KEY`，程序打印缺少的项并以退出码 1 结束。

## 运行时会启动什么

端口空闲时，流水线自己启动服务，工作目录都是仓库根目录：

- 后端：`python backend/app.py`，端口 5000，地址 `http://localhost:5000`
- 前端：先在 `frontend/` 执行 `npm install`，再执行 `npm run dev --prefix frontend`，端口 5173，地址 `http://localhost:5173`

页面地址是 `/register`、`/login`、`/home`。端口上已经有进程时直接复用，不再启动第二个。流水线结束后这两个进程继续留在后台。

只想生成用例和页面脚本、先不打开 Demo：

```powershell
python pipeline/run.py --dry-run
```

浏览器要看得见：

```powershell
python pipeline/run.py --headed
```

只跑某一条需求，或只跑接口、只跑页面：

```powershell
python pipeline/run.py --req REQ-REG-002
python pipeline/run.py --channel api
python pipeline/run.py --channel ui
```

把需求规格说明书一并交给模型（不要把已有测试报告和 Bug 单放进去）：

```powershell
python pipeline/run.py --docs docs/srs/登录注册Demo-需求规格说明书.md
```

## 结果放在哪里

文档写在当前目录下的 `AIgen-docs/`：

| 文件 | 何时出现 |
| --- | --- |
| `AIgen-docs/测试用例.md` | 模型给出用例之后 |
| `AIgen-docs/测试执行记录.md` | 执行结束并决定输出结论时 |
| `AIgen-docs/测试报告.md` | 同上 |
| `AIgen-docs/BUG-编号-标题.md` | 有失败用例时，同一需求合并成一张 |

页面脚本在 `pipeline/work/ui/`。失败截图在 `pipeline/work/screenshots/`。这些文件不覆盖 `docs/` 里已有的手工文档。

页面脚本退出码 `0` 表示出现了预期文案，`1` 表示没有。按当前实现，不足 6 位的用户名仍能注册成功，对应用例应为失败，并写入 Bug 单。

## 单独看一条页面脚本

前后端已经在 5173 和 5000 上运行时，可以单独执行示例：

```powershell
python pipeline/example/register_short_username.py
Write-Host "退出码: $LASTEXITCODE"
```

标准输出是一段【执行结果】。截图在 `pipeline/example/last-result.png`。
